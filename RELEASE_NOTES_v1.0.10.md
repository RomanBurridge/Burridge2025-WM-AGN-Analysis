# WM-AGN Analysis Code v1.0.10

Version v1.0.10 supersedes the published v1.0.9 archive for reproduction of
the final revised manuscript.  The v1.0.9 record remains preserved at
`10.5281/zenodo.22051996`.

## Changes from v1.0.9

- Incorporates the authoritative Task 28 continuum-product closeout.
- Expands the final machine-readable continuum table from 425 to 501 rows:
  485 image-based measurements and 16 literature measurements.
- Adds the complete recovery inventory and the reviewed alias, failed-product,
  bandwidth-smearing, boundary-rejection, admission, and identity records.
- Regenerates the selected 230 GHz reference fluxes and all dependent
  variability, contamination, table, SED, and BHS-size-versus-flux products.
- Preserves the deterministic black-hole parameter and uncertainty workflow
  introduced in v1.0.9.

The archive contains code and lightweight machine-readable products.  Raw
telescope data, FITS files, CASA images, measurement sets, and logs remain in
their external archives and are not redistributed here.

The v1.0.10 version DOI is `10.5281/zenodo.22121490`.
