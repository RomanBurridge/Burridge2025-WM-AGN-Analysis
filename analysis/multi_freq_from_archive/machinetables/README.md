# Machine-Readable Tables

## `fitsummary_machine.txt`

Full continuum-fitting table used for the paper's archival/SMA continuum compilation. The columns are fixed-width and correspond to:

1. Source name
2. Telescope/instrument
3. Observing frequency in GHz
4. Peak flux density in mJy beam^-1; an asterisk indicates a 3-sigma upper limit
5. Observation date label in `yyyy/mm/dd_x` format
6. Synthesized beam FWHM in arcsec
7. Fit SNR
8. Archive filename or literature reference

For ALMA rows, `member.uid___...` filenames identify Member OUS data products that can be resolved through the ALMA Science Archive. For VLA rows, filenames are NVAS image products. SMA rows refer to the newly reduced SMA products generated by the scripts in this release.

## `S230_extrapolation_comparison.csv`

Reference-flux table used for the revised 230 GHz analysis. It gives the selected 200--400 GHz anchor observation for each source, the adopted extrapolated `S_230_mJy` value using `alpha_fid = -0.7`, and the model range obtained from `alpha = -1.0` and `alpha = -0.4`.

## `variability_machine.txt` and `correlations_machine.txt`

Diagnostic machine-readable outputs from the variability workflow. These are not used as rendered paper tables, but they preserve the pairwise comparison products from `Variability_Search.ipynb`.

The files were cleaned with `analysis/multi_freq_from_archive/clean_variability_tables.py` to restore observation dates from `fitsummary_final_withextras.txt` and remove warning lines that had been captured by table-output redirection. The cleaning report is written to `variability_table_cleaning_report.txt`.
