# Zenodo Upload Checklist

1. Create a new version of the existing WM-AGN Analysis Code Zenodo record if one exists; otherwise create a new upload.
2. Upload the final `WM_AGN_Zenodo_release.zip` file.
3. Resource type: `Software`.
4. Title: `WM-AGN Analysis Code`.
5. Creators: use the final author/creator list you want in the citation.
6. Description: paste/adapt `ZENODO_DESCRIPTION.md`.
7. Keywords: use the keyword list in `ZENODO_DESCRIPTION.md`.
8. License: choose before publishing. A permissive software license such as MIT is common for code, but this is your call.
9. Reserve or publish the DOI.
10. Submit the draft to the `AAS Journals` community for review.
11. After the DOI is stable, update the paper bibliography entry for `Burridge2026` to point to this exact Zenodo version.
