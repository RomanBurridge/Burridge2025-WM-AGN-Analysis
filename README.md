# WM-AGN Analysis Code

This archive contains the analysis code and lightweight machine-readable tables for the manuscript

**When the Shadow Meets Its Measure: Assessing the Feasibility of Submillimeter Black Hole Shadow Imaging in Megamaser Disk AGN**

The code calibrates and images SMA observations, gathers and fits archival ALMA/VLA continuum products, estimates compact continuum flux densities, converts the selected 200--400 GHz anchor measurements to a common 230 GHz reference frequency, computes black-hole-shadow angular sizes, estimates contamination from thermal dust and extended jets, and produces the tables/figures used in the paper.

Large telescope data products are intentionally not included in this Zenodo archive. See `DATA_ACCESS.md` for instructions on retrieving ALMA, VLA/NVAS, and SMA data from their public archives.

## Contents

- `BH_Parameters.ipynb`: computes black-hole-shadow diameters and uncertainty propagation for the megamaser-disk sample.
- `VLBI_sensitivity.ipynb`: computes representative VLBI sensitivity and angular-resolution quantities.
- `analysis/CountingBHS_and_Spectra/BHS_params.csv`: machine-readable black-hole-shadow parameter table generated by `BH_Parameters.ipynb`.
- `analysis/sma_calibration/`: SMA calibration and imaging scripts, observing-script text files, molecular-line flag list, and the SMA MIR-to-measurement-set conversion helper.
- `analysis/multi_freq_from_archive/`: continuum fitting, archival-flux compilation, 230 GHz extrapolation, contamination estimates, variability-screening notebooks, and plotting notebooks.
- `analysis/multi_freq_from_archive/machinetables/fitsummary_machine.txt`: full machine-readable continuum-fitting table corresponding to the printed table in the paper.
- `analysis/multi_freq_from_archive/machinetables/S230_extrapolation_comparison.csv`: 230 GHz reference-flux table, including the adopted spectral index and the alpha range used to assess model sensitivity.

The archival FITS files, raw SMA data, CASA image products, CASA logs, measurement sets, and local environment files are excluded.

## Python/CASA Dependencies

The analysis uses both a normal Python environment and a CASA-capable Python environment.

Core Python packages:

- `numpy`
- `scipy`
- `pandas`
- `matplotlib`
- `astropy`
- `astroquery`
- `requests`
- `pyuvdata` for SMA MIR conversion
- `jupyter`

CASA-side packages:

- CASA 6 with `casatasks` and `casatools`
- `analysisUtils` for coordinate conversion utilities used during ALMA fitting

The shell scripts accept `PYTHON_BIN=/path/to/casa-python` when a CASA-specific interpreter is needed.

## Reproducing the Main Workflow

Run notebooks from the release root so that relative paths resolve correctly.

1. Retrieve the external telescope data following `DATA_ACCESS.md`.
2. Place ALMA, VLA/NVAS, and SMA products under:
   - `analysis/multi_freq_from_archive/ALMA/`
   - `analysis/multi_freq_from_archive/VLA/`
   - `analysis/multi_freq_from_archive/SMA/`
   - `analysis/sma_calibration/sma_data/`
3. Convert SMA MIR data to CASA measurement sets if needed:
   ```bash
   cd analysis/sma_calibration/sma_data
   python sma2casa.py 230316_128
   ```
4. Calibrate/image SMA observations using a CASA-capable interpreter:
   ```bash
   cd analysis/sma_calibration
   PYTHON_BIN=/path/to/casa-python python calibrate_sma_dirty.py --date 230316 --flagnum 2 --sciniter 0
   PYTHON_BIN=/path/to/casa-python python calibrate_sma_clean.py --date 230316 --flagnum 2 --sciniter 6
   ```
5. Fit continuum images:
   ```bash
   cd analysis/multi_freq_from_archive
   PYTHON_BIN=/path/to/casa-python bash run_continuum_fits_dirty.sh
   PYTHON_BIN=/path/to/casa-python bash run_continuum_fits_clean.sh
   ```
6. Generate the 230 GHz reference-flux comparison:
   ```bash
   cd analysis/multi_freq_from_archive
   python s230_reference.py \
     --source-text fitsumfiles/final/fitsummary_final_withextras.txt \
     --output-csv machinetables/S230_extrapolation_comparison.csv
   ```

The notebooks `post_processing_finalcontinuum.ipynb`, `Beam_Date_Flux_Graphs.ipynb`, `flux_size_graph.ipynb`, `get_contams.ipynb`, and `get_alpha.ipynb` generate the paper plots and source-specific continuum/contamination tables after continuum fitting is complete.

## Notes on Machine Tables

`fitsummary_machine.txt` gives the full continuum-fitting summary table. For ALMA rows, filenames beginning with `member.uid___...` identify ALMA Member OUS products that can be resolved through the ALMA Science Archive. For VLA rows, filenames are NVAS image products and can be resolved through the NRAO VLA/NVAS archive services. See `DATA_ACCESS.md`.

The variability-screening code is included because it was used as a diagnostic workflow. The diagnostic `variability_machine.txt` and `correlations_machine.txt` products are included in `analysis/multi_freq_from_archive/machinetables/` for reproducibility, but they are not rendered as paper tables. They were cleaned with `clean_variability_tables.py` to restore fit-summary observation dates and remove warning lines from the machine-table body.
